# assets/ — plugin artwork

`icon.svg` (36×36 viewBox, currentColor) and `icon-512.png` are the bundle's display artwork,
derived from the upstream `dsh-btw-marginalia` assets. Both are original/derivative artwork under
the same Apache-2.0 license as the rest of this plugin.

Keep `package.json` → `files` in sync when adding an asset. Do not hotlink remote images from the
Web UI.
